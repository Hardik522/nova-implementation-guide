PRIVACY & CONTROL

Understand what leaves your computer.

Strict model privacy

Blocks cloud inference and model catalogs. This setting covers model routing; network tools have separate permissions.

Guarded model privacy

Applies best-effort redaction of known credentials and selected sensitive patterns before cloud model requests. Review your content; detection is incomplete.

Reviewed actions

Requests requiring approval show the operation and arguments. Approvals are single-use and expire after two minutes. Voice cannot approve.

Local records

Tasks, contacts and drafts use local storage. Windows credentials use the platform protection mechanism. Keep backups private and protect your computer account.

QUESTIONS, ANSWERED

Before your first task.

Does Nova need a paid API key?

No. Free Mode uses local models and tools. Local model processing consumes your computer resources. Optional providers may bill separately, even if a free quota is offered.

Will adding one key unlock every feature?

No. Each provider or tool has its own adapter, credentials and permissions. A key does not implement a missing integration or activate services automatically.

Can Nova make a website?

Yes. The demo command creates a static HTML file. Website and project commands generate bounded templates or source for review. Production deployment, store payments and full application validation require additional work.

Can I use English, Hindi or Gujarati?

Speech recognition offers English, Hindi, Gujarati and Auto settings. Accuracy depends on the speech model, microphone and recording. Spoken output depends on installed system voices.

Does it work on my phone?

Responsive screens and installation assets are included. The current server is local to your laptop. Secure remote hosting and actual Android/iPhone testing remain necessary.

Is every planned feature finished?

No. The expanded feature audit contains partial and pending items. Automated checks cover selected behavior, not every real device, account or production deployment.
